📌 Installation & Setup

1️⃣ Prerequisites
Ensure you have the following installed:

.NET SDK (>= .NET 6.0)
SplashKit SDK
A C# compatible editor (VS Code, Visual Studio, JetBrains Rider, etc.)

2️⃣ Clone Repository
git clone https://github.com/Sufian-code/thot-tech.git

3️⃣ Install Dependencies
If using NuGet, restore dependencies:
dotnet restore

4️⃣ Build & Run the Project
Build the Project
dotnet build

Run the Project
dotnet run
